FAQ

Frequently asked questions

Common questions about btc-seed, security, and usage.

Is btc-seed safe to use for real wallets?+
btc-seed generates entropy locally using the operating system's cryptographic random source and makes no network calls. For best safety, run it on an offline or air-gapped Windows machine and verify the release checksum before launching.
Does the app ever send my seed phrase anywhere?+
No. btc-seed has zero network functionality — no telemetry, no analytics, no update pings. Every mnemonic, address, and keypair is computed and stored only on your device.
Which BIP standards are supported?+
btc-seed supports BIP39 mnemonic generation and verification, BIP32 hierarchical deterministic keys, and BIP44 derivation paths for Bitcoin. Both legacy and native SegWit address formats are available.
How does vanity address generation work?+
The generator repeatedly creates keypairs and checks each derived address against your desired pattern. Longer patterns take exponentially more time — start with 3–4 characters and let the multi-threaded engine use your CPU cores.
